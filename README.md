# Parking Map

## Навігація

Кнопка «Моє місцеперебування» запитує браузерний дозвіл лише після натискання. Пункт прибуття вибирається з popup POI або правим кліком на карті. Для автомобільного маршруту використовується [Geoapify Routing API](https://apidocs.geoapify.com/docs/routing/) (`mode=drive`, GeoJSON з кроками). Синя лінія показується лише після успішної відповіді сервісу. GPS передається Geoapify тільки під час розрахунку маршруту; історія позицій не зберігається. Режим навігації використовує `watchPosition`, зупиняє його через `clearWatch`, показує точність GPS та повертає стрілку тільки за надійним компасом або GPS heading. Перерахунок після відхилення потребує 15 секунд сталого відхилення понад `max(80 м, 2 × accuracy)` і має паузу щонайменше 60 секунд.

Для роботи маршруту створіть ключ Geoapify й **спочатку обмежте його** в MyProjects дозволеним HTTP referrer/origin `https://ghut-corporation.github.io` (та власним доменом, якщо він є). Після цього додайте його як GitHub Actions Secret `GEOAPIFY_KEY`. Workflow включає ключ у браузерний `map-config.js`: це публічний клієнтський ключ, а GitHub Secret захищає лише вихідний репозиторій і лог збірки. Для локального перегляду додайте `localhost` до дозволених джерел ключа. Без ключа сайт показує пояснення й не імітує маршрут. За [поточними умовами Geoapify](https://www.geoapify.com/pricing/) безкоштовний план має 3000 кредитів на день і до 5 запитів за секунду; перевіряйте умови перед розгортанням. Сервіс не підтверджує актуальні перекриття або безпеку дороги.

Статичний сайт для публікації на GitHub Pages. Для роботи сайту не потрібні власний сервер, Node.js сервер або `.env`.

## Публікація на GitHub Pages

1. Створіть репозиторій GitHub і додайте файли проєкту.
2. У **Settings → Secrets and variables → Actions** створіть repository secret з назвою `MAPTILER_KEY` та значенням ключа зі свого MapTiler Cloud.
3. У MapTiler обмежте ключ дозволеними HTTP origins: `ВАШ_АКАУНТ.github.io` та, якщо використовується, вашим власним доменом. Для локального попереднього перегляду за потреби додайте `localhost` і `127.0.0.1`.
4. У **Settings → Pages** виберіть **GitHub Actions** як джерело публікації.
5. Надішліть зміни у гілку за замовчуванням або запустіть workflow вручну на вкладці **Actions** з цієї гілки.

Workflow збирає каталог `dist` зі статичних файлів і підставляє `MAPTILER_KEY` лише в артефакт розгортання. `.env` не потрібен і проігнорований Git. У браузері ключ буде видимий у запитах MapTiler, як і будь-який ключ для клієнтської карти; його потрібно обмежити дозволеними доменами та квотами у MapTiler.

Після першого успішного workflow адреса матиме вигляд `https://ВАШ_АКАУНТ.github.io/НАЗВА_РЕПОЗИТОРІЮ/`. Відносні шляхи `./styles.css`, `./map-config.js` та `./script.js` працюють у підкаталозі проєктного сайту.

## Картографічні сервіси

MapLibre GL JS завантажується з CDN, а стиль і векторні тайли — з MapTiler Cloud. GeoJSON кордонів України з geoBoundaries зберігається у `data/ukraine-boundary.geojson` і входить до Pages-публікації. Сайту потрібен інтернет для MapTiler.

GitHub Pages можна використовувати безкоштовно для публічного репозиторію. У MapTiler Cloud є безкоштовний план для тестування, особистого та некомерційного використання з лімітами; після вичерпання квоти сервіс призупиняється до наступного місяця, доки не буде змінено план. Перевіряйте актуальні умови MapTiler перед публікацією сайту широкій аудиторії або комерційним використанням.

## Об’єкти інфраструктури (POI)

Початковий вигляд зосереджений на Львові ([24.0297, 49.8397], zoom 13). Локальний `data/lviv-poi.geojson` охоплює суцільну прямокутну область `23.93–24.13° E`, `49.78–49.90° N`: центр, північні, південні, східні та західні міські квартали. Його отримано 1 листопада 2026 року одноразовим послідовним експортом невеликих bbox з [OSM API v0.6](https://wiki.openstreetmap.org/wiki/Api06). Файл містить 2 139 унікальних OSM-об’єктів: 1 728 парковок без підтвердження платності, 101 з `fee=yes`, 52 зарядки, 90 АЗС і 168 СТО. Порівняно з попереднім зрізом додано 1 949 нових ID; 12 старих записів без відповідних поточних POI-тегів прибрано. Це статичний зріз наявного OSM-картографування, а не гарантія повноти або актуальності кожного об’єкта. Записи мають OSM type/id, координати та наявні назву й характеристики. Дані © OpenStreetMap contributors, ліцензія [ODbL 1.0](https://www.openstreetmap.org/copyright). Поза локально охопленими ділянками діє запит до Overpass, якщо сервіс доступний.

Кнопки інструментів незалежно перемикають шари з реальних даних OpenStreetMap через `https://overpass-api.de/api/interpreter`. Парковки та платні парковки доступні з zoom 13, зарядки й АЗС — з 11, СТО — з 12. На загальному вигляді України запити не виконуються. Маркери мають кольори відповідних значків у панелі; натискання відкриває дані OSM.

Теги: `amenity=parking`, `amenity=charging_station`, `amenity=fuel`, `shop=car_repair`. `fee=yes` відносить парковку до платних, `fee=no` означає безкоштовну. Інші парковки залишаються у загальній категорії: відсутність `fee` не означає безкоштовність. Умови `fee:conditional` показуються в popup без спроб обчислити поточну вартість. Приватні об’єкти позначаються тегом доступу в popup, якщо він є в OSM.

Завантажуються вузли, контури та відношення для видимої області, обрізаної до географічного охоплення України. Для контурів використовується центр bbox з Overpass; точки додатково перевіряються за локальним полігоном України. Локальні й мережеві точки об’єднуються за OSM type/id без дублікатів. Весь viewport перевіряється на покриття сукупністю локальних ділянок; якщо він покритий, запит до Overpass не потрібний. Наявність двох окремих записів OSM про один заклад автоматично не виправляється.

Debounce — 700 мс, мінімальна пауза між запитами — 5 секунд, кеш до 16 округлених областей на 5 хвилин та клієнтський ліміт 30 запитів на добу в одному браузері. Запити до надмірної області блокуються з підказкою наблизити карту. Застарілі запити скасовуються. При HTTP 502 локальні та вже завантажені точки залишаються видимими; можлива лише одна автоматична повторна спроба через 30 секунд. Після другого 502 запити призупиняються на 5 хвилин; рух карти не запускає їх знову. Після паузи користувач може вручну перемкнути категорію для нової спроби. При HTTP 406/429 або таймауті інтерфейс повідомляє категорію помилки та чекає перед наступною спробою користувача. Публічний Overpass може бути тимчасово недоступним і не гарантує повноти даних.

Модуль `poi.js` копіюється до Pages artifact разом з `script.js`. Backend та додаткові ключі для POI не потрібні. Джерела правил тегування: https://wiki.openstreetmap.org/wiki/Key:fee та https://wiki.openstreetmap.org/wiki/Tag:shop%3Dcar_repair.
