# Parking Map

## Навігація

Кнопка «Моє місцеперебування» запитує браузерний дозвіл лише після натискання. Пункт прибуття вибирається з popup POI або правим кліком на карті. Для автомобільного маршруту використовується [Geoapify Routing API](https://apidocs.geoapify.com/docs/routing/) (`mode=drive`, GeoJSON з кроками). Синя лінія показується лише після успішної відповіді сервісу. GPS передається Geoapify тільки під час розрахунку маршруту; історія позицій не зберігається. Режим навігації використовує `watchPosition`, зупиняє його через `clearWatch`, показує точність GPS та повертає стрілку тільки за надійним компасом або GPS heading. Перерахунок після відхилення потребує 15 секунд сталого відхилення понад `max(80 м, 2 × accuracy)` і має паузу щонайменше 60 секунд.

Для роботи маршруту створіть ключ Geoapify й **спочатку обмежте його** в MyProjects дозволеним HTTP referrer/origin `https://ghut-corporation.github.io` (та власним доменом, якщо він є). Після цього додайте його як GitHub Actions Secret `GEOAPIFY_KEY`. Workflow включає ключ у браузерний `map-config.js`: це публічний клієнтський ключ, а GitHub Secret захищає лише вихідний репозиторій і лог збірки. Для локального перегляду додайте `localhost` до дозволених джерел ключа. Без ключа сайт показує пояснення й не імітує маршрут. За [поточними умовами Geoapify](https://www.geoapify.com/pricing/) безкоштовний план має 3000 кредитів на день і до 5 запитів за секунду; перевіряйте умови перед розгортанням. Сервіс не підтверджує актуальні перекриття або безпеку дороги.

Статичний сайт для публікації на GitHub Pages. Для роботи сайту не потрібні власний сервер, Node.js сервер або `.env`.

## Публікація на GitHub Pages

1. Створіть репозиторій GitHub і додайте файли проєкту.
2. У **Settings → Secrets and variables → Actions** створіть repository secret з назвою `MAPTILER_KEY` та значенням ключа зі свого MapTiler Cloud.
3. У MapTiler обмежте ключ дозволеними HTTP origins: `ВАШ_АКАУНТ.github.io` та, якщо використовується, вашим власним доменом. Для локального попереднього перегляду за потреби додайте `localhost` і `127.0.0.1`.
4. У **Settings → Pages** виберіть **GitHub Actions** як джерело публікації.
5. Надішліть зміни у гілку за замовчуванням або запустіть workflow вручну на вкладці **Actions** з цієї гілки.

Workflow збирає каталог `dist` зі статичних файлів і підставляє `MAPTILER_KEY` лише в артефакт розгортання. `.env` не потрібен і проігнорований Git. У браузері ключ буде видимий у запитах MapTiler, як і будь-який ключ для клієнтської карти; його потрібно обмежити дозволеними доменами та квотами у MapTiler.

Після першого успішного workflow адреса матиме вигляд `https://ВАШ_АКАУНТ.github.io/НАЗВА_РЕПОЗИТОРІЮ/`. Відносні шляхи `./styles.css`, `./map-config.js` та `./script.js` працюють у підкаталозі проєктного сайту.

## Картографічні сервіси

MapLibre GL JS завантажується з CDN, а стиль і векторні тайли — з MapTiler Cloud. GeoJSON кордонів України з geoBoundaries зберігається у `data/ukraine-boundary.geojson` і входить до Pages-публікації. Сайту потрібен інтернет для MapTiler.

GitHub Pages можна використовувати безкоштовно для публічного репозиторію. У MapTiler Cloud є безкоштовний план для тестування, особистого та некомерційного використання з лімітами; після вичерпання квоти сервіс призупиняється до наступного місяця, доки не буде змінено план. Перевіряйте актуальні умови MapTiler перед публікацією сайту широкій аудиторії або комерційним використанням.

## Мобільний інтерфейс

До 768 px (також у невисокій горизонтальній орієнтації з coarse pointer) той самий екземпляр MapLibre займає `100dvh`. П’ять наявних перемикачів стають нижньою панеллю іконок з `aria-label`; активні категорії та локальний кеш зберігаються. Відступи кнопок враховують `safe-area-inset-*`, `viewport-fit=cover`; `ResizeObserver` змінює розмір canvas без створення нової карти або маршруту. Компас показує реальний bearing і повертає карту на північ; кнопка GPS використовує чинний обробник.

Після вибору пункту показуються верхня інструкція і нижні кнопки «Поїхати»/«Скасувати»; категорії доступні в компактному меню P. «Поїхати» запускає чинний GPS watch, а після запуску доступна кнопка «Стежити». «Скасувати» прибирає маршрут і зупиняє watch, не скидаючи POI. Деталі маневрів, назви вулиць і український текст запитуються через `details=instruction_details,route_details&lang=uk` згідно з [документацією Geoapify](https://apidocs.geoapify.com/docs/routing/). Відстань до маневру обчислюється вздовж отриманої геометрії; час позначено як приблизний. Якщо даних інструкції немає, інтерфейс показує це явно. Помилки GPS/API залишаються видимими; інформаційні повідомлення про успіх у мобільному режимі доступні для screen reader без постійної текстової панелі.

Темна мобільна палітра застосовується до фактичних географічних шарів Streets v4 без заміни тайлів, фільтрів, дорожніх товщин або геометрії. Під час переходу на десктоп відновлюються збережені початкові значення paint, включно з виразами. Десктопні карта, інструменти, навігація та попередження зберігають початкове компонування.

Перевірка UI: `node scripts/check_mobile_ui.cjs` з окремо встановленим Playwright (`PARKING_PLAYWRIGHT_PATH`, за потреби `PARKING_CHROME_PATH`, `PARKING_SCREENSHOT_DIR`). Тест охоплює 360/390/430/768/1024/1440 px, порівнює десктопні розміри та paint із HEAD, перевіряє перемикачі, popup, компас, запуск/скасування та збереження стану при resize. Використовуються реальні тайли і локальні POI; GPS і Routing API контрольовані. Це не перевірка фізичного GPS, Safari на iPhone або живого Geoapify.

## Об’єкти інфраструктури (POI)

Початковий вигляд зосереджений на Львові ([24.0297, 49.8397], zoom 13). Локальний `data/lviv-poi.geojson` охоплює оброблену область `23.75–24.35° E`, `49.65–50.05° N`. За справжніми адміністративними полігонами OSM перевірено, що вона повністю охоплює Львів, Винники, Брюховичі, Рудне (назва OSM «Рудно»), Сокільники, Зимну Воду, Малехів та Дубляни. Полігони збережено в `data/lviv-poi-coverage.geojson`, результати перевірки й обліку — у `data/lviv-poi-audit.json`. Обробка всієї області не гарантує, що всі наявні в реальності об’єкти нанесені в OSM або досі працюють.

Джерело розширення — готовий [витяг України Geofabrik](https://download.geofabrik.de/europe/ukraine.html), зріз OSM **2026-10-31 21:23:06 UTC**, отриманий та оброблений 1 листопада 2026 року. Завантажено один PBF; повторних масових запитів до OSM API/Overpass немає. Збережено новіші значення попереднього локального зрізу OSM API від 1 листопада. Походження, дата, SHA-256 витягу та OSM type/id записані в metadata/властивостях GeoJSON. Дані © OpenStreetMap contributors, ліцензія [ODbL 1.0](https://www.openstreetmap.org/copyright).

Додано **731 новий OSM ID**; збережено 2 137 попередніх ID. Два старі вузли АЗС об’єднано з однойменними полігонами, усередині яких вони розташовані; відсутні у полігона характеристики перенесено. Ще один новий вузол СТО об’єднано за тією самою перевіркою. Для цього є таблиця відповідності ID, яка також запобігає поверненню дублікатів при поєднанні з Overpass. 2 164 `parking_space`, геометрії яких повністю містяться у вже врахованій парковці, відображаються як кількість нанесених місць батьківської парковки; **129 самостійних місць** залишено окремими POI з відповідною назвою типу в popup. 76 доріг з тегами паркування не перетворено на додаткові маркери: сегмент дороги не доводить існування окремої парковки. Site-відношення перевіряються як групи об’єктів; без придатної геометрії окремі координати для них не вигадуються. Детальні списки доданих ID, об’єднань і вкладених місць наведено в audit.

Розмір основного GeoJSON: **592 196 → 891 289 байтів**. Браузер завантажує тільки цей регіональний файл, один раз за сеанс роботи карти, після ввімкнення категорії з відповідним zoom і перетину її видимої області з локальним покриттям. Використовуються HTTP-кеш, індекс категорій і кеш перевірок меж України. На карту передаються лише точки у viewport, через п’ять MapLibre circle layers, без DOM-маркерів для кожного POI. Аудит і адміністративні полігони не завантажуються для звичайного показу карти.

Кнопки інструментів незалежно перемикають шари з реальних даних OpenStreetMap через `https://overpass-api.de/api/interpreter`. Парковки та платні парковки доступні з zoom 13, зарядки й АЗС — з 11, СТО — з 12. На загальному вигляді України запити не виконуються. Маркери мають кольори відповідних значків у панелі; натискання відкриває дані OSM.

Теги: `amenity=parking`, `amenity=parking_space` (локальний витяг), `amenity=charging_station`, `amenity=fuel`, `shop=car_repair`. Магазини `car`, `car_parts`, `tyres` додаються до СТО тільки з явним `service:vehicle:car_repair=yes`, `service:vehicle:tyres_repair=yes` або `service:vehicle:oil_change=yes`; сам `shop=tyres` не доводить ремонт. `fee=yes` чи явна позитивна ціна з валютою у `fee` підтверджує платність. Позитивний тариф `charge` враховується за відсутності суперечливого `fee` і `fee:conditional`. `fee=no` означає безкоштовну. Відсутність `fee` не означає безкоштовність. Умови `fee:conditional` показуються без обчислення поточної вартості. Приватний або заборонений доступ явно зазначено в popup; приватні об’єкти не називаються загальнодоступними.

Popup зберігає кнопку «Прокласти маршрут» та показує тільки наявні характеристики: оплату, доступ і його умови, capacity, тип парковки, оператора, графік, контакти, роз’єми/потужність зарядок, паливо та послуги СТО. Довгий popup прокручується, щоб кнопка маршруту залишалася доступною на смартфоні.

Для локальних контурів і multipolygon-відношень обчислено точку всередині справжньої геометрії; попередні координати також перевірено. Усі точки перевірено за межею України. Весь viewport перевіряється на покриття локальними даними; за повного покриття Overpass не викликається навіть коли знайдено нуль об’єктів. Поза покриттям діє обмежений запит Overpass для видимої області. Live-відповідь містить node/way/relation та центри bbox для контурів; `parking_space` у цьому режимі не запитується, оскільки без повних полігонів неможливо надійно перевірити вкладеність. Локальні та live-точки об’єднуються за OSM type/id і підтвердженими відповідностями ID. Інші близькі заклади автоматично не зливаються.

Debounce — 700 мс, мінімальна пауза між запитами — 5 секунд, кеш до 16 округлених областей на 5 хвилин та клієнтський ліміт 30 запитів на добу в одному браузері. Запити до надмірної області блокуються з підказкою наблизити карту. Застарілі запити скасовуються. При HTTP 502 локальні та вже завантажені точки залишаються видимими; можлива лише одна автоматична повторна спроба через 30 секунд. Після другого 502 запити призупиняються на 5 хвилин; рух карти не запускає їх знову. Після паузи користувач може вручну перемкнути категорію для нової спроби. При HTTP 406/429 або таймауті інтерфейс повідомляє категорію помилки та чекає перед наступною спробою користувача. Публічний Overpass може бути тимчасово недоступним і не гарантує повноти даних.

При недоступності локального файла показується окреме пояснення; повторне завантаження можливе після оновлення сторінки. Поза локальним регіоном залишається Overpass. Модулі та всі три файли локальної бази копіюються до Pages artifact. Backend та додаткові ключі для POI не потрібні. Джерела правил: [fee](https://wiki.openstreetmap.org/wiki/Key:fee), [parking_space](https://wiki.openstreetmap.org/wiki/Tag:amenity%3Dparking_space), [service:vehicle](https://wiki.openstreetmap.org/wiki/Key:service:vehicle:*).

Відтворення офлайн-обробки (Python з `osmium` і `shapely`, окремо від клієнтського сайту): `python scripts/build_lviv_poi.py INPUT.osm.pbf RAW_CACHE.json BASELINE.geojson`. BASELINE — збережений початковий файл перед розширенням; не підставляйте замість нього вже згенерований результат. Існуючий RAW_CACHE дозволяє повторити збірку без сканування PBF; PBF потрібен для перевірки SHA-256. Витяг і кеш не входять у сайт. Перевірка даних без мережі: `node scripts/check_lviv_poi.mjs`. Браузерна перевірка: `node scripts/check_lviv_browser.cjs` з окремо встановленим Playwright (шлях у `PARKING_PLAYWRIGHT_PATH`, за потреби `PARKING_CHROME_PATH`). Вона використовує реальні тайли MapTiler і локальні POI, але контрольовані відповіді Geoapify/Overpass; це не перевірка доступності реального Routing API.
