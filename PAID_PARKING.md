**Нові 31 записи — сегменти вуличного паркування у Львові, а не 31 окремий паркувальний майданчик.** Маркер стоїть посередині геометрії відповідного OSM way. Він не означає, що вся однойменна вулиця платна, і не позначає конкретне вільне місце. Обидві сторони одного way представлені одним POI. У popup явно вказано тип сегмента та сторону за напрямком OSM.

Джерело — [OpenStreetMap через офіційний витяг Geofabrik](https://download.geofabrik.de/europe/ukraine.html), зріз **2026-11-02T21:21:26Z**, отримано й оброблено 2026-11-03. Дані © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright). Попередній PBF/кеш не знайдено після пошуку в проєкті, Downloads, TEMP і профілі користувача; один новий PBF збережений у виключеній з Git `.local-cache/`. Повторний запуск використовує кеш, без мережевих запитів.

Один новий сегмент має `parking:left:fee=yes`; 30 — старі `parking:condition:left/right/both=ticket`. Семантику перевірено за [сучасною схемою OSM Street parking](https://wiki.openstreetmap.org/wiki/Street_parking) та [документацією старого parking:condition](https://wiki.openstreetmap.org/wiki/Key:parking:condition). `ticket` означає вимогу оплати паркування, а не дозвіл на бронювання. Додаються лише сегменти з явним фізичним паркуванням; `no`, `separate`, невідома платність та неоднозначні часові правила не перетворюються на підтверджену платну парковку. Теги конкретної сторони мають пріоритет над `both`. Умови, тарифи й обмеження показуються тільки за наявності в джерелі; поточна вартість і вільні місця не обчислюються.

Повні початкові геометрії нових сегментів, доказ платності, координати, дата, SHA-256 PBF/кешу та результати перевірок збережені в `data/lviv-poi-audit.json → paidExpansion`. Маркери перевірені щодо джерельної лінії та меж України; прийняті сегменти не накладаються один на одного. `way/24567664` і `way/641312704` не додано через перетин з уже наявним паркінгом `relation/3362858`. Усі попередні 2 894 записи збережено без зміни значень.

Нових підтверджених платних POI у передмістях у цьому витягу не знайдено. У межах адміністративного Львова тепер 134 платні записи, Винників — 2, ще один — у решті обробленої області. Для Брюховичів, Рудного, Сокільників, Зимної Води, Малехова та Дублян нові точки не вигадуються. Відсутність підтверджених тегів не доводить відсутність платних парковок у реальності.

Додатково перевірено один цільовий Overpass POST (HTTP 406) і один пакетний запит 76 відомих way через OSM API (HTTP 429). Повторів, ротації серверів і підміни ідентичності не було. [Офіційний API ЛеоПарковки](https://parking.lviv.ua/api/lots) повернув HTTP 200 і 135 записів з геометрією, але явну ліцензію повторного використання цього експорту не підтверджено; його не імпортовано. [Старий міський відкритий набір](https://test.data.gov.ua/dataset/parking) має CC BY, проте позначений як неоновлений (2020), а посилання на ресурс недоступне під час перевірки. Офіційні тарифи не перенесено довільно на OSM-об’єкти.

## Демонстраційне бронювання

Кнопка **«Забронювати»** є тільки для категорії `paid` із повторною перевіркою тегів через `categoryFor`. У решти чотирьох категорій її немає. Звичайний **«Прокласти маршрут»** збережений.

Перше натискання пояснює: це особистий демонстраційний вибір без резервування місця та без оплати. Лише **«Підтвердити демо-вибір»** змінює стан і запускає наявний `navigation.setDestination`. Потрібний GPS-дозвіл запитує наявний механізм; при відмові показано інструкцію та можливість повторити через GPS-кнопку карти. Geoapify отримує координати тільки для маршруту. Неонові маршрутні шари, геометрія, інструкції, відстань і час залишаються наявними. Помилка API показується без вигаданого маршруту.

Зберігається один вибір у пам’яті поточного екземпляра карти; він не передається іншим відвідувачам і скидається при повному перезавантаженні сторінки. Відкриття/закриття popup, перемикання категорій, переміщення та заміна MapLibre style його зберігають. У передані до наявного paid source дані додається тимчасова властивість `demoSelected`; вихідні GeoJSON не змінюються. `circle-color` вибраного POI — `#8A909C`, обвідка — `#C5CAD4`; радіус маркерів та інші категорії збережено. Нових DOM-маркерів, джерел і шарів для вибору немає.

**«Скасувати бронювання»** прибирає особистий вибір. Навігація зберігає непрозорий token власника пункту призначення; `clearDestinationFor(token)` очищає лише пов’язаний маршрут, включно з незавершеними GPS/API-запитами. Пізні відповіді не повертають скасований маршрут. Новий звичайний маршрут, навіть до тих самих координат, не скасовується. Вибір іншої платної парковки замінює попередній.

Точка інтеграції майбутнього офіційного API — підтвердження/скасування в `poi.js`. Наразі там тільки локальний demo-state і виклики навігації. Реальний booking provider повинен окремо повертати перевірене підтвердження оператора; поточний demo-state таким підтвердженням не є. Немає платежів, номерів бронювань, обіцянки вільних місць або блокування для інших людей.

## Відтворення й перевірки

Офлайн-розширення: `python scripts/expand_paid_parking.py INPUT.osm.pbf RAW_CACHE.json` формує звіт для перегляду; лише додатковий `--apply` змінює основний GeoJSON та аудит через наявний механізм staged/atomic writes. Попередня копія залишається у `.local-cache/`. Потрібні офлайн Python-залежності osmium/Shapely, клієнтський сайт їх не використовує.

- `node scripts/check_paid_parking.mjs` — реальні 31 сегмент, підтвердження тегів, GeoJSON, ID, координати, походження й відхилення.
- `node scripts/check_lviv_poi.mjs` та `node scripts/check_vehicle_poi.mjs` — всі категорії, дедуплікація, адміністративні підрахунки й збереження попередніх автомобільних даних.
- `node scripts/check_poi_audit.mjs` — демо-кнопка лише для платних, підтвердження/відмова, подвійний клік, заміна/скасування, gray-state, стиль, кеш, помилки Overpass та cleanup.
- `node scripts/check_navigation_audit.mjs` — GPS/Geoapify, відмова й повтор GPS, скасування pending-запитів, незалежність іншого маршруту, 401/403/429/timeout, повторний style.
- `node scripts/check_booking_browser.cjs` — браузерні сценарії desktop/mobile з реальними тайлами MapTiler і локальними POI; GPS та Geoapify контрольовані. Потрібні окремо Playwright/Chrome (`PARKING_PLAYWRIGHT_PATH`, `PARKING_CHROME_PATH`, опційно `PARKING_SCREENSHOT_DIR`).
- `python scripts/check_pages_audit.py`, `python scripts/check_data_tools.py`, `node --check`, Python AST і `git diff --check`.

GitHub Pages залишається статичним. Workflow вже копіює основний GeoJSON, `poi.js`, `navigation.js`, `script.js`, CSS і HTML у dist; додаткового runtime-файла немає. Відносні шляхи збережено, версії клієнтських ресурсів оновлено для кешу. PBF, пакети перевірок і сирий кеш не публікуються. Commit/push/deploy не виконуються.

Живий запит Geoapify з особистим GPS, польова доступність парковок, фізичний GPS та Safari/iPhone не підтверджені контрольованими тестами.

## Фактичні результати фінальних прогонів

Усі перелічені офлайн-перевірки, JavaScript syntax, Python AST і `git diff --check` пройшли. Імпортер повторно виконано з `--apply`: SHA-256 обох production-файлів до/після однакові; додаткового сканування PBF або мережевих запитів немає. Порівняння з початковим Git HEAD підтвердило збереження всіх 2 894 попередніх features без зміни значень.

`check_booking_browser.cjs` пройшов 1440/390/320 px: п’ять категорій, новий справжній сегмент `way/39762750`, відсутність booking у решти категорій, підтвердження без попереднього запиту маршруту, сірий source/paint, автоматичний маршрут, скасування, незалежність іншого маршруту, вибір іншої парковки, style reload та контрольована відповідь 403. Основний GeoJSON завантажено один раз, Overpass-запитів немає, попереджень стилю немає.

Повний `check_mobile_ui.cjs` також пройшов **320/360/375/390/430/768/1024/1440 px**, порівняння десктопної геометрії й paint з HEAD, усі категорії, GPS watch/clear, компас, popup, маршрутизацію, три заміни style та збереження стану при resize. Єдиний запис console error — **навмисно змодельований HTTP 403 Geoapify** для перевірки обробки відмови; неконтрольованих JavaScript-помилок і попереджень стилю немає. Перші пробні прогони виявили перекриття popup атрибуцією та нестабільність координат тестового кліку до завершення responsive resize; обидва виправлено. В одному проміжному повному прогоні були попередження sprite; у фінальному повному й фокусованому прогонах вони не повторилися, логування не вимикалося.

Змінені runtime-файли: `poi.js`, `navigation.js`, `script.js`, `styles.css`, `index.html`. Дані: `data/lviv-poi.geojson`, `data/lviv-poi-audit.json`. Документація/виключення кешу: `README.md`, `PAID_PARKING.md`, `.gitignore`. Перевірки й офлайн-імпорт: `scripts/expand_paid_parking.py`, `scripts/check_paid_parking.mjs`, `scripts/check_booking_browser.cjs`, `scripts/check_mobile_ui.cjs`, `scripts/check_poi_audit.mjs`, `scripts/check_navigation_audit.mjs`. Workflow та браузерна конфігурація ключів не змінювалися.
